# max-cli

Ваш личный аккаунт [MAX](https://max.ru) в терминале и в ИИ-агентах. `max` — командная строка и
MCP-сервер: читайте и пишите в чаты сами или поручите это Claude, Codex, Cursor и другим агентам.

> ⚠️ **max-cli использует неофициальный внутренний API MAX.** API может измениться без
> предупреждения, а использование инструмента может нарушать условия сервиса. Вы используете
> max-cli на свой риск; авторы и контрибьюторы не несут ответственности за блокировки аккаунтов,
> потерю данных или другие последствия.

```sh
npm install -g @leemour/max-cli
max session start qr               # один раз: сканируете QR-код приложением MAX
max chats list --limit 5
max messages list "Иван Петров"
max messages send "Иван Петров" "буду в семь"
```

## Как это работает

`max` работает от вашего имени, как ещё одно ваше устройство, а не как бот. Вы входите один раз
по QR-коду, и дальше доступно то же, что в приложении: чаты, сообщения, файлы, группы, контакты и
профиль.

Агенту `max` подключается одним из двух способов:

- **Агент с терминалом** — Claude Code, Codex, Gemini CLI. Он сам вызывает команды `max`. Дайте
  ему навык (skill) — инструкцию, как работать с `max`: одна команда, см.
  [ниже](#для-скриптов-и-агентов).
- **Агент без терминала** — Claude Desktop, Cursor и другие клиенты MCP. Подключите `max mcp`.
  По умолчанию агент только читает. Отправку можно разрешить, в том числе с вашим подтверждением
  каждого сообщения.

## Что умеет

- **Читать.** Чаты, история, одно сообщение вместе с соседними, непрочитанное во всех чатах
  сразу (`max inbox`), новые сообщения по мере прихода (`max watch`), скачивание вложений.
- **Искать.** Сообщения — по тексту всего прочитанного, без подключения к MAX. Чаты и контакты —
  по части названия или имени.
- **Писать.** Текст и разметка, ответы, фото и файлы, правка, пересылка, закрепление, реакции.
- **Вести группы и каналы.** Создать группу, вступить по ссылке, выйти, участники и админы,
  название и настройки, заявки на вступление, ссылка-приглашение, папки.
- **Контакты и аккаунт.** Найти человека по номеру, добавить, удалить, импортировать из файла;
  изменить профиль; посмотреть и завершить другие сеансы.
- **Входить удобным способом.** QR-код прямо в терминале, QR-код или SMS через web.max.ru в
  браузере, или готовый токен.

## Чем он хорош

- **Читает незаметно.** Чтение не ставит отметку «прочитано»: собеседник не видит, что вы открыли
  чат.
- **Агент не напишет лишнего.** Есть профиль только для чтения, список чатов, в которые можно
  писать, и лимит сообщений в час. MCP-сервер может показывать вам каждое сообщение до отправки.
  Если имя подходит к двум чатам, `max` не выбирает сам, а показывает оба.
- **Сообщение не уйдёт дважды.** Если связь оборвалась во время отправки, `max` прямо говорит, что
  не знает, дошло ли сообщение, и даёт команду для повтора. MAX узнаёт повтор и второго сообщения не
  создаёт.
- **Своя копия переписки.** Всё прочитанное сохраняется на вашем компьютере. По ней работает
  быстрый поиск по тексту сообщений, и её можно читать без интернета (`--offline`). При входе MAX
  присылает только то, что изменилось. Стереть копию — `max cache clear`.
- **Пароль от аккаунта не лежит в файле.** Токен входа хранится в системном хранилище паролей:
  Keychain в macOS, Secret Service (GNOME Keyring, KWallet) в Linux, диспетчер учётных данных в
  Windows. В историю команд он не попадает.
- **Скрипту и агенту легко разобрать ответ.** С `--json` команда отдаёт только данные, в одной и
  той же форме, без текста для человека вокруг. Ошибка приходит отдельно и с номером, поэтому
  скрипт сразу понимает, что случилось: нет входа, чат не найден или MAX не ответил вовремя.
- **Разбор проблем без вашей переписки.** `--trace` показывает каждый запрос к MAX, чтобы понять,
  почему команда не сработала. В этой записи нет текстов, имён, телефонов и токена, поэтому её
  можно приложить к сообщению об ошибке. Без флага ничего не записывается.

## Чем отличается от других

Для MAX уже есть хорошие проекты, и max-cli многому у них научился.
[PyMax](https://github.com/MaxApiTeam/PyMax) — самая полная библиотека для личного аккаунта; её код
помог разобрать многие операции протокола. Выбирайте то, что подходит под задачу.

|---|:-:|:-:|:-:|
| что это | командная строка и MCP-сервер | библиотека на Python | MCP-сервер на PyMax |
| чтение, отправка текста, фото и файлов | ✅ | ✅ | ✅ |
| реакции, правка, пересылка, закрепление | ✅ | ✅ | — |
| группы и каналы: создать, вступить, участники, админы | ✅ | ✅ | чтение каналов |
| контакты, профиль, другие сеансы | ✅ | ✅ | — |
| новые сообщения в реальном времени | ✅ `max watch` | ✅ обработчики событий | — |
| видео, голосовые, кружки | — | ✅ | — |
| опросы | — | ✅ | — |
| отложенная отправка | — | ✅ | — |
| удаление сообщений, отметка «прочитано» | — | ✅ | — |
| пароль и двухфакторный вход, фото профиля | — | ✅ | — |
| свои боты и автоответы на аккаунте | — | ✅ | — |
| работа без своей программы — готовые команды | ✅ | — | — |
| MCP-сервер и навык для агентов | ✅ | — | MCP |
| ограничения для агента: только чтение, список чатов, лимит в час, подтверждение | ✅ | — | — |
| локальная копия с поиском и чтением без интернета | ✅ | — | — |

Если нужен бот со своим аккаунтом, а не ваш личный аккаунт, — это официальный

## Установка

Пакет — **`@leemour/max-cli`**, команда, которую он ставит, — **`max`**. Имя без области занято
чужим пакетом с 2018 года.

Запустить, ничего не устанавливая:

```sh
npx @leemour/max-cli --help
```

Поставить насовсем:

```sh
npm install -g @leemour/max-cli
max --version
```

Нужен **Node 22 или новее**, либо **Bun 1.3+**. Подробности, переменные окружения и то, куда
ложатся файлы, — [docs/installation.md](docs/installation.md).

## Вход

`max session start qr` рисует QR-код в терминале: вы сканируете его приложением MAX, и токен входа
сохраняется в системном хранилище паролей. Ещё способы — `qr-chrome`, `sms` (оба через web.max.ru в браузере) и `token`
([docs/sessions.md](docs/sessions.md)).

```sh
max session start qr                   # QR-код в терминале
max session start                      # или спросит токен, не отображая ввод
pass show max/token | max session start # или из трубы
max account show                       # кто вы
```

Несколько аккаунтов — несколько профилей, и профиль называется **первым словом**, а не флагом:

```sh
max chats list              # профиль default
max personal chats list     # профиль personal
export MAX_PROFILE=personal # или на всю сессию оболочки
```

## Использование

```sh
max chats list --limit 5
max contacts list                     # люди, с кем есть личный чат
max messages list 0 --limit 50        # по id чата
max messages list "Иван Петров"       # или по части названия
max messages send 0 "текст"
```

Списки листаются одинаково везде, а история — по времени, потому что она к нему и привязана:

```sh
max contacts list --limit 5 --page 2  # шестой по десятый
max contacts list --all --order name  # всё, по алфавиту
max messages list 0 --before 2026-09-20T01:00:00Z
```

Что делала команда:

```sh
max chats list --trace     # показать по строке на запрос, ничего не сохраняя
max chats list --record      # сохранить, ничего не показывая
max runs list                # что делалось, новое сверху
max runs show <id>
```

Локальная копия — чтобы было чем ответить без сети:

```sh
max chats list --offline
max cache clear
```

Полностью: [docs/usage.md](docs/usage.md). Каждая команда и каждая опция:
[docs/commands.md](docs/commands.md) — эта страница собирается из самой программы, поэтому описать
версию, которой не существует, она не может.

## Для скриптов и агентов

### Навык для агентов с терминалом

Навык (skill) — файл с инструкцией, который агент читает перед работой. В навыке `max` описано,
какие команды есть, что агент делает только по вашей просьбе и как безопасно повторить отправку.
Его понимают **Claude Code**, **Codex** и **Gemini CLI**. Навык ставится одной командой и всегда
той же версии, что и `max`:

```sh
# Claude Code
mkdir -p ~/.claude/skills/max-cli && max skill show > ~/.claude/skills/max-cli/SKILL.md
# Codex и Gemini CLI — общая папка ~/.agents/skills
mkdir -p ~/.agents/skills/max-cli && max skill show > ~/.agents/skills/max-cli/SKILL.md
```

Как эти агенты находят навыки: [Codex](https://learn.chatgpt.com/docs/build-skills),
[Gemini CLI](https://geminicli.com/docs/cli/skills/).

### MCP-сервер для агентов без терминала

Claude Desktop, Cursor и другие клиенты MCP подключаются к `max mcp` и работают с тем же
аккаунтом. Без `--allow-send` агент только читает. С `--confirm-send` перед каждой отправкой вы
видите чат и текст и отвечаете «да» или «нет». Подробно — [docs/mcp.md](docs/mcp.md).

```sh
claude mcp add max -- max mcp
```

### Ответы в JSON

```sh
max chats list --json
```

С `--json` команда печатает только данные в JSON, без таблиц, цвета и подсказок. Так же она
работает, когда её вывод читает другая программа, — например, в конвейере `max … | jq`. Любой
список приходит в одной и той же форме:

```json
{ "items": [ … ], "page": 1, "limit": 20, "hasMore": true }
```

Ошибка приходит отдельно от данных, поэтому её нельзя принять за пустой результат:

```json
{"error":{"code":"authentication_error","message":"no session for profile \"default\" — run `max session start`"}}
```

У каждой ошибки есть номер — код завершения программы. По нему скрипт решает, что делать дальше:
`4` — нужно войти, `6` — чат или сообщение не найдены, `9` — MAX не ответил вовремя, `14` —
неизвестно, ушло ли сообщение. Все коды — в [docs/commands.md](docs/commands.md).

## Разработка

```sh
pnpm install
pnpm lint && pnpm typecheck && pnpm test
pnpm build && pnpm smoke:bun          # собранная команда под вторым рантаймом
pnpm generate                         # переписать сгенерированные файлы
```

Протокол MAX неофициальный и разобран обратной инженерией: это не Bot API. Каждый опкод и форма
каждого сообщения объявлены один раз в `src/spec/`, а реестр, типизированный клиент и
[docs/protocol.md](docs/protocol.md) из них генерируются — и CI падает, если дерево устарело.

Половина, не имеющая отношения к MAX — потоки вывода, рендерер, коды ошибок, хранилище паролей, часы, —
вынесена в [`@leemour/cli-core`](https://github.com/leemour/cli-core) и общая с `braze-cli`.

## Дорожная карта

Ближайшее:

- голосовые сообщения и видео;
- опросы: показывать при чтении и голосовать;
- отложенная отправка — сообщение уйдёт в назначенное время, даже если компьютер выключен;
- отметка «прочитано» по флагу, только когда вы попросили;
- локальная копия по желанию — можно работать совсем без неё.

Весь список — [docs/ROADMAP.md](docs/ROADMAP.md).
