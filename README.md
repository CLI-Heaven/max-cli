Командная строка для личного аккаунта [MAX Messenger](https://max.ru): чаты, сообщения, группы и
контакты из терминала, из скрипта или из агента.

> ⚠️ **max-cli использует неофициальный внутренний API MAX.** API может измениться без
> предупреждения, а использование инструмента может нарушать условия сервиса. Вы используете
> max-cli на свой риск; авторы и контрибьюторы не несут ответственности за блокировки аккаунтов,
> потерю данных или другие последствия.

```sh
npm install -g @leemour/max-cli
max session start qr               # один раз: сканируете QR-код приложением MAX
max chats list --limit 5
max messages list "Иван Петров"
max messages send "Иван Петров" "буду в семь"
```

## Как это работает

`max` подключается к тому же серверу, что и веб-клиент [web.max.ru](https://web.max.ru), и входит
с токеном вашей сессии. Бот не нужен, всё делается от вашего имени. Каждый
запуск — одна операция: подключиться, сделать, напечатать результат, отключиться. В терминале
результат — таблица или лента сообщений; в скрипте и у агента — одно значение JSON. Прочитанное
сохраняется в локальную копию, поэтому поиск и повторное чтение работают без сети.

## Что умеет

- **Читать.** Чаты, история, одно сообщение вместе с соседними, непрочитанное во всех чатах
  сразу (`max inbox`), скачивание вложений.
- **Искать.** Сообщения — по тексту прочитанного, в локальной копии, без подключения к MAX. Чаты и
  контакты — по части названия или имени.
- **Писать.** Текст и разметка, ответы, фото и файлы, правка, пересылка, закрепление, реакции.
- **Вести группы и каналы.** Создать группу, вступить по ссылке, выйти, участники и админы,
  название и настройки, заявки на вступление, ссылка-приглашение, папки.
- **Контакты и аккаунт.** Найти человека по номеру, добавить, удалить, импортировать из файла;
  изменить профиль; посмотреть и завершить другие сеансы.
- **Работать с агентами.** MCP-сервер `max mcp` для Claude Desktop и Cursor. Инструкция для агента
  `max skill show` для Claude Code, Codex и Gemini CLI.
- **Входить удобным способом.** QR-код прямо в терминале, QR-код или SMS через web.max.ru в
  браузере, или готовый токен.

## Чем он хорош

- **Чтение не отмечает сообщения прочитанными.** Собеседник не увидит, что вы открыли чат. Команду
  «прочитано» `max` не отправляет никогда, и это проверяет тест.
- **Защита от отправки не туда.** Профиль только для чтения, список разрешённых чатов, лимит
  сообщений в час, журнал каждой попытки без текста. MCP-сервер может спрашивать владельца перед
  каждой отправкой. Имя, которое подходит к двум чатам, — это отказ со списком кандидатов.
- **Точный исход отправки.** Если ответ от MAX не пришёл, команда говорит `outcome_unknown` и
  даёт `--cid` для повтора. Повтор с тем же `--cid` не создаёт второго сообщения.
- **Токен хранится в ключнице ОС.** Он не попадает в файл настроек, в аргументы команды и в
  историю оболочки.
- **Вывод для машин.** С `--json` на stdout ровно одно значение JSON, все списки одной формы, у
  каждой ошибки есть код возврата. Диагностика идёт только на stderr.
- **Диагностика без переписки.** `--trace` и `--record` показывают операции, id, размеры и время,
  но не тексты, имена, телефоны и токен. По умолчанию не записывается ничего.
- **Node 22+ и Bun 1.3+.** CI запускает собранную команду под обоими.

## Чем отличается от других

| | Что это | Когда выбрать |
|---|---|---|
| **max-cli** | командная строка и MCP-сервер для личного аккаунта | читать и писать из терминала, скриптов и агентов; одна операция на запуск |
| [PyMax](https://github.com/MaxApiTeam/PyMax) | библиотека на Python для личного аккаунта | своя программа на Python, которая работает постоянно и отвечает на события в реальном времени |
| [max-mcp](https://github.com/renosaza/max-mcp) | MCP-сервер на PyMax | агент в клиенте MCP, которому хватает чтения чатов и отправки сообщений и файлов |
| [Bot API MAX](https://dev.max.ru/docs) | официальный API для ботов | бот с собственным аккаунтом, а не ваш личный |

## Установка

Пакет — **`@leemour/max-cli`**, команда, которую он ставит, — **`max`**. Имя без области занято
чужим пакетом с 2018 года.

Запустить, ничего не устанавливая:

```sh
npx @leemour/max-cli --help
```

Поставить насовсем:

```sh
npm install -g @leemour/max-cli
max --version
```

Нужен **Node 22 или новее**, либо **Bun 1.3+**. Подробности, переменные окружения и то, куда
ложатся файлы, — [docs/installation.md](docs/installation.md).

## Вход

`max session start qr` рисует QR-код в терминале: вы сканируете его приложением MAX, и токен уходит
в ключницу. Ещё способы — `qr-chrome`, `sms` (оба через web.max.ru в браузере) и `token`
([docs/sessions.md](docs/sessions.md)).

```sh
max session start qr                   # QR-код в терминале
max session start                      # или спросит токен, не отображая ввод
pass show max/token | max session start # или из трубы
max account show                       # кто вы
```

Несколько аккаунтов — несколько профилей, и профиль называется **первым словом**, а не флагом:

```sh
max chats list              # профиль default
max personal chats list     # профиль personal
export MAX_PROFILE=personal # или на всю сессию оболочки
```

## Использование

```sh
max chats list --limit 5
max contacts list                     # люди, с кем есть личный чат
max messages list 0 --limit 50        # по id чата
max messages list "Иван Петров"       # или по части названия
max messages send 0 "текст"
```

Списки листаются одинаково везде, а история — по времени, потому что она к нему и привязана:

```sh
max contacts list --limit 5 --page 2  # шестой по десятый
max contacts list --all --order name  # всё, по алфавиту
max messages list 0 --before 2026-09-20T01:00:00Z
```

Что делала команда:

```sh
max chats list --trace     # показать по строке на запрос, ничего не сохраняя
max chats list --record      # сохранить, ничего не показывая
max runs list                # что делалось, новое сверху
max runs show <id>
```

Локальная копия — чтобы было чем ответить без сети:

```sh
max chats list --offline
max cache clear
```

Полностью: [docs/usage.md](docs/usage.md). Каждая команда и каждая опция:
[docs/commands.md](docs/commands.md) — эта страница собирается из самой программы, поэтому описать
версию, которой не существует, она не может.

## Для скриптов и агентов

```sh
max chats list --json
```

`--json` — это **ровно одно значение JSON на stdout и больше ничего**: ни спиннера, ни галочки, ни
предупреждения. То же самое включается само, когда stdout не терминал. Любой список отвечает одним
объектом — `{ "items": […], "page": 1, "limit": 20, "hasMore": true }` — и `--all` с `--offline`
отвечают **тем же**, чтобы разбирающему ответ не приходилось ветвиться на две формы.

Ошибка уходит на stderr, а stdout остаётся пустым, поэтому отказ невозможно принять за результат:

```json
{"error":{"code":"authentication_error","message":"no session for profile \"default\" — run `max session start`"}}
```

Ветвиться надо по коду возврата: `4` — нет сессии, `6` — не найдено, `9` — таймаут, `14` — исход
неизвестен, `130` — прервано. Вся таблица — в [docs/commands.md](docs/commands.md).

**Инструкция для агента** — не список флагов, а ловушки и границы: что нельзя делать без просьбы,
почему id — строки, как повторять отправку. Ставится одной строкой, той же версии, что и `max`.
Файл один и тот же, различается только папка:

```sh
# Claude Code
mkdir -p ~/.claude/skills/max-cli && max skill show > ~/.claude/skills/max-cli/SKILL.md
# Codex и Gemini CLI — общая папка ~/.agents/skills
mkdir -p ~/.agents/skills/max-cli && max skill show > ~/.agents/skills/max-cli/SKILL.md
```

Где какая среда ищет навыки: [Codex](https://learn.chatgpt.com/docs/build-skills),
[Gemini CLI](https://geminicli.com/docs/cli/skills/).

**Для клиентов без терминала** — Claude Desktop, Cursor — тот же профиль по MCP. Без `--allow-send`
сервер только читает. Подробно — [docs/mcp.md](docs/mcp.md).

```sh
claude mcp add max -- max mcp
```

## Разработка

```sh
pnpm install
pnpm lint && pnpm typecheck && pnpm test
pnpm build && pnpm smoke:bun          # собранная команда под вторым рантаймом
pnpm generate                         # переписать сгенерированные файлы
```

Протокол MAX неофициальный и разобран обратной инженерией: это не Bot API. Каждый опкод и форма
каждого сообщения объявлены один раз в `src/spec/`, а реестр, типизированный клиент и
[docs/protocol.md](docs/protocol.md) из них генерируются — и CI падает, если дерево устарело.

Половина, не имеющая отношения к MAX — потоки вывода, рендерер, коды ошибок, ключница, часы, —
вынесена в [`@leemour/cli-core`](https://github.com/leemour/cli-core) и общая с `braze-cli`.
