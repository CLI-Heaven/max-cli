# Дорожная карта

Что планируется в `max`. Порядок примерный и может меняться. Предложить своё можно в
[issues](https://github.com/leemour/max-cli/issues).

## Ближайшее

- **Голосовые сообщения.** Отправлять запись как голосовое, а не как файл.
- **Видео.** Отправлять видео как видео, с превью.
- **Опросы.** Показывать опрос при чтении и голосовать.
- **Похожесть на официальный клиент.** Отправлять то же, что официальное приложение, и сообщать о
  себе те же сведения об устройстве.
- **Фото профиля.**

## Позже

- **Локальная копия по желанию.** Настройка, с которой `max` ничего не сохраняет на диск и всё
  берёт из MAX.
- **Боты.** Команды для своего бота MAX через официальный Bot API.
- **Действия по событию.** Запуск своей команды, когда пришло новое сообщение.
- **Двоичный протокол веб-клиента** вместо текстового JSON.
- **Кружки** и **вход с облачным паролем**.
- **Установщики** для каждой платформы, без Node и Bun.

## Не планируется

- **Удаление чатов.**
